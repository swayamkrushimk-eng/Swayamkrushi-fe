# Swayamkrushi-fe

Official frontend application for Swayamkrushi NGO website and broadsheet editorial platform.

## Built with
- React 19 + Vite
- Modern Newspaper & Broad-sheet Editorial Design
- Cloudinary Media Integration
- Glassmorphic Pro Video Player with Custom Controls

## Getting Started

### Prerequisites
- Node.js (v18+)
- npm or yarn

### Installation
```bash
npm install
```

### Development
```bash
npm run dev
```

### Production Build
```bash
npm run build
```
